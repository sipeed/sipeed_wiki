常见问题

供电与连接

屏幕反复重启或闪烁

通常是供电不足。T256S 运行 AI 超分时功耗较高，对供电的稳定性有要求：

  • 换一根质量好的 USB-C 数据线，线太长、太细时压降大。
  • 接电脑时直接插在电脑的 USB 口上，不要经过供电不足的扩展坞。
  • 插在手机上时，确认手机电量充足，没有开省电模式。
  • 换一个充电宝或充电器再试。

插到手机上没有反应

  1. 确认 T256S 插到底。手机壳太厚时插头可能插不到位，先取下手机壳再试。
  2. 部分安卓手机需要先在设置里打开 OTG，有些机型一段时间不用会自动关闭，可以在设置里搜索"OTG"。
  3. 屏幕亮了但手机上看不到画面时：用摄像头 App 的，确认 App 支持 UVC，并在弹出的 USB 权限提示里点了"确定"；用网页的，见下面的"浏览器打不开 192.168.17.1"。

iPhone 和 iPad 能用吗

  • iPhone：不支持 UVC 摄像头，相机类 App 看不到 T256S。USB-C 接口的 iPhone 可以用 Safari 打开 192.168.17.1 使用网页；iPhone 不会自动弹出网页，需要手动输入地址。
  • iPad：USB-C 接口的 iPad 可以用支持 UVC 的相机 App 看画面，例如 CamX - USB Camera。

详见快速上手。

电脑上看不到摄像头

  1. 换一根数据线再试。只能充电的线没有数据功能，电脑识别不到任何设备。
  2. 换一个 USB 口，尽量直接插在电脑上。
  3. Windows 打开"设备管理器"，看"照相机"或"图像设备"下有没有新设备；Linux 执行 lsusb，应能看到 ID 为 359f:4201 的设备。
  4. 确认没有别的程序正在占用摄像头。同一时间只有一个程序能打开 UVC 摄像头。

浏览器打不开 192.168.17.1

请依次检查：

  1. 固件是否为 26.40.0 或更高版本。更早的版本没有网页，查看方法见查看固件版本。
  2. 地址是否为 192.168.17.1，前面不要加 https://。
  3. 刚插上时等几秒钟，等系统识别出这块网络再打开。
  4. 安卓手机请先打开飞行模式。安卓系统会把 USB 网络排在 Wi-Fi 和移动数据之后，浏览器的请求会先走 Wi-Fi 或移动数据，自然打不开 T256S。打开飞行模式后再输入地址；如果飞行模式下 Wi-Fi 仍然开着，把 Wi-Fi 也关掉。用完记得关闭飞行模式。
  5. 电脑上检查是否多出一块网卡，并且拿到了 192.168.17.x 的地址。如果拿到的是 169.254.x.x，说明自动获取地址失败，可以手动设置为 192.168.17.100，子网掩码 255.255.255.0。
  6. 改过网段的设备，地址是 192.168.<网段>.1，见下一个问题。

改了网段后打不开网页

新地址是 192.168.<你选的数字>.1。忘了数字时，从屏幕顶边往下拉打开状态面板，FW 那一行后面就是当前地址。详见同时接多台设备。

手机提示"网络无法访问互联网"

这是正常的。T256S 提供的是一个只连着你手机的本地网络，本来就不能上网，保持连接即可。

屏幕与画面

屏幕界面和文档里的不一样

本文档按固件 26.47.0 编写。旧版固件（26.17.1 及之前）的屏幕右侧是一列竖排的按钮：点色块按钮切换伪彩，点圆形按钮拍照，点相册按钮查看照片，长按圆形按钮查看版本号。旧版固件没有网页和 HTTP 接口，建议按更新固件升级到 26.47.0。

顶部下拉或底部上滑没有反应

这两个手势都要从屏幕边缘开始滑，从画面中间开始滑会被当成切换伪彩。另外，状态面板打开时要先把它收起，才能从底边打开相册。

屏幕上的文字是倒着的

打开状态面板，点旋转按钮，屏幕提示 TAP AGAIN 时再点一次，按钮和文字就会旋转 180°。这只旋转界面，不旋转热成像画面。

手机上看到的画面方向不对

T256S 插在手机底部时，画面相对手机是倒过来的：

  • 用 UVC 摄像头 App 时，在 App 里把画面旋转 180°，或者同时打开水平镜像和垂直镜像。
  • 用网页时，点顶部的旋转按钮。
  • 用 iPad 时，在相机 App 里旋转画面。

关掉屏幕上的超分后，摄像头画面还是超分的

正常。状态面板里的 SR 开关只控制屏幕显示。UVC 摄像头的 MJPEG 画面始终是超分画面；网页上用顶部的 SR 按钮在超分和原生画面之间切换。

画面偶尔停顿一下，还有轻微的"咔哒"声

这是红外模组在做挡片校准（NUC）：模组会定期合上内部的挡片，补偿传感器随温度产生的漂移。校准时画面会短暂停顿，属于正常现象。

超分效果有时明显，有时不明显

超分擅长增强边缘、线条和纹理，比如电路板走线、元件轮廓、机械零件边缘，这类场景提升最明显。大面积温度均匀、缺少纹理的平面，比如白墙、均热板，可以增强的细节少，提升就不明显。想直观对比，可以用网页的超分对比。

画面噪点多

  • 刚开机时，等 2 ~ 5 分钟，让设备达到热平衡。
  • 目标和环境的温差越小，噪点越明显。
  • 环境温度过高（例如超过 40 ℃）时热噪声会增加，建议在 15 ~ 35 ℃ 的环境下使用。

测温

测量的温度不准

请检查以下几点：

  • 表面材质：T256S 按发射率 0.95 计算温度，适合皮肤、塑料、电路板、墙面等大多数非金属表面。光亮的金属（铝箔、不锈钢等）反射很强，读数会明显偏低。可以在被测位置贴一小块黑色电工胶带或喷哑光黑漆，等它和物体温度一致后再测。
  • 距离与目标大小：在 1 米外，每个像素大约对应 4 mm。目标太小时会和周围的温度混在一起，精确测温建议在 0.2 ~ 1 米的距离内进行。
  • 环境反射：周围有高温物体（阳光、烙铁等）时，它们的热辐射可能经被测表面反射进镜头，让读数偏高。
  • 预热：刚开机时读数会漂移，等 2 分钟左右再测。
  • 微距镜头：装上微距镜头后读数会有一定误差，需要准确读数时取下再测。

屏幕右侧的 HI 和 LO 是什么

是当前的测温档位。HI 是高增益档，-15 ~ 150 ℃，精度更高，是默认档位；LO 是低增益档，50 ~ 500 ℃，量程更大。画面里超过 130 ℃ 的区域多于十分之一时，T256S 会自动切到 LO；画面几乎全部降到 110 ℃ 以下后，自动切回 HI。不需要手动设置，见读温度。

画面上的颜色能代表温度吗

不能。伪彩只表示画面里的相对冷热，每一帧都会按当时的最低温和最高温重新分配颜色。需要具体数值时，以屏幕上的温度读数为准，或者用网页的多点测温。

摄像头录下来的视频里没有温度数据

UVC 的 MJPEG 画面已经上了伪彩，颜色不再对应温度。需要温度时，用 UVC 的 Y16 格式（192 × 256），或者用 HTTP 接口的 /frame.temp16、/api/v1/thermal，不要从彩色画面反推。详见UVC 输出格式。

Y16 原始数据怎么换算成温度

温度（℃）= 像素值 ÷ 64 − 273.15。这个公式只适用于 192 × 256 的 Y16；480 × 640 的 Y16 是超分后的灰度画面，不是温度。示例见从 Y16 读取温度。

照片与文件

屏幕上拍的照片存在哪里

存在设备里。把 T256S 插到电脑上，打开新出现的 U 盘，照片在 Gallery 文件夹里，文件名记录了拍摄时的中心、最低和最高温度，见照片与 U 盘。

打开相册提示 GALLERY EMPTY

设备里还没有照片。点拍照按钮拍一张，再从屏幕底边往上滑打开相册。运行升级工具升级后，照片也会被清空。

网页上拍的照片和录像存在哪里

由浏览器直接保存到当前的手机或电脑上，一般在"下载"文件夹里。照片文件名以 thermal- 开头，录像为 thermal-record.mp4 或 .webm。它们不会存进 T256S。

电脑上 U 盘里的照片和屏幕上的不一致

电脑正在使用 U 盘时，在屏幕上拍照或删除照片，两边看到的内容可能不一致。在电脑上安全弹出 U 盘，再拔插一次 T256S 即可。以后先安全弹出，再在屏幕上拍照或删除。

固件与开发

怎么查看固件版本

26.17.1 之后的版本：从屏幕顶边往下拉打开状态面板，FW 后面就是版本号，也可以在网页底部的"设备设置与固件更新"里查看。26.17.1 及之前的版本：长按屏幕上的拍照按钮。详见查看固件版本。

怎么更新固件

26.17.1 及之前的设备，在电脑上运行升级工具，一次升级到 26.47.0；26.17.1 之后的设备，直接在网页上升级。26.17.1 及之前的设备不能直接在网页上升级。详见更新固件。

升级工具找不到设备

  • 确认 T256S 已经用数据线连接电脑，并且电脑上能看到它的 U 盘。
  • 关掉正在占用这个 U 盘的程序（例如打开着 Gallery 文件夹的窗口）后重试。
  • Linux 上可以先运行 ./Linux/t256s-migrate info 列出候选磁盘，必要时用 --mount <路径> 指定 T256S 的 U 盘后重新运行。
  • 工具提示设备可能正在转换时，不要重启设备，等几分钟再检查版本。

网页升级时提示固件被拒绝

  • 确认下载的是 T256S 的 .sysupgrade.bin 文件，没有解压，也没有改名。
  • 文件可能下载不完整，重新下载一次。
  • 如果"安全系统更新"一栏显示"需要 USB 迁移"，说明设备还是旧的单分区系统，要先运行升级工具。

升级后黑屏

升级过程中设备会重启多次，黑屏一段时间是正常的，保持供电，等设备自动进入画面即可。长时间黑屏、无法开机时，请联系 support@sipeed.com。

升级过程中断电了

立即重新接上电源，等设备自动恢复。网页升级有回退机制，新系统启动失败时会回到升级前的版本；运行升级工具的过程没有断电保护，断电后可能无法开机，这时请联系 support@sipeed.com 返修，不要自行拆机。

能用程序读取温度吗

可以。把 T256S 插到电脑上，设备会在 http://192.168.17.1 上提供 HTTP 接口：/api/v1/thermal 返回中心、最高和最低温度，/frame.temp16 返回每个像素的原始温度，/frame.jpg 返回伪彩画面。Python、Go、Node.js、shell 都能调用，也可以直接交给 AI 工具。详见 HTTP 接口和 AI 接入。

网页和 HTTP 接口需要什么固件版本

26.40.0 或更高版本。26.17.1 及之前的设备，先按运行升级工具升级到 26.47.0。

可以在 Linux 或树莓派上用吗

可以。T256S 是标准的 UVC 摄像头，Linux（V4L2）免驱，guvcview、cheese、ffplay 和 OpenCV 都能打开，设备的 USB ID 为 359f:4201。网页和 HTTP 接口在 Linux 上同样可用。

设备工作时发热，正常吗

正常。T256S 内部有运行 AI 超分的处理器，工作时会发热，铝合金外壳负责散热。请在通风的环境下使用，不要长时间放在密闭的高温空间里。

还没解决

请发邮件到 support@sipeed.com，附上手机或电脑的型号和系统版本，以及 T256S 的固件版本号。
