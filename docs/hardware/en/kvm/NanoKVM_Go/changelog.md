# Documentation Changelog

## V1.0.0

- Created this page to centralize documentation updates for NanoKVM Go / NanoKVM Go+.
- Added the NetBird remote network guide, covering installation, enabling, SSO login, and external access; added Chinese and English screenshots and sidebar entries. The guide also notes that the integration currently uses NetBird Cloud only and does not enable LAN subnet routes or DNS.
- Added Chinese and English Sipeed Remote Network disclaimer pages for direct access from the device QR code; the pages are URL-only, with Chinese and English screenshots and a ✓/✕ note.
- Added the ZeroTier remote network guide, covering installation, joining a network, authorization in ZeroTier Central, and external access; added Chinese and English screenshots and sidebar entries.
- Rewrote the frp guide: the client is now installed and configured in the web interface under `Settings` > `Remote Network` > `FRP`, so the manual frpc installation over SSH is gone; examples now use 0.71.0, status, disable, and uninstall sections are new, and the screenshots were replaced.
- Added the image mounting and file sharing guide, which covers disk mounting and file sharing on one page: image upload and URL download, mass storage and CD-ROM modes, shared volume initialization and disabling, and attaching or taking the volume back on the target machine. Chinese and English screenshots, sidebar entries, and a user guide link are included.
