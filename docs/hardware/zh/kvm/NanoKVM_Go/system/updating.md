## 进入系统重置

进入系统重置前，请准备一根 USB 线和一枚卡针。操作过程中需要保持卡针按压，直到屏幕进入固定显示状态后再松开。

1. 将卡针插入 NanoKVM Go 顶部两个 Type-C 接口中间的小孔，并保持按压。

![NanoKVM Go 插入卡针](./../../../../assets/NanoKVM/go/reset/nanokvm-go-reset-pin-hole.webp)

2. 在卡针保持按压的状态下，将 USB 线插入带有屏幕标志的 Type-C 接口。

![NanoKVM Go 插入 USB 线](./../../../../assets/NanoKVM/go/reset/nanokvm-go-reset-usb-cable.webp)

3. 等待一会儿，直到屏幕持续显示如下状态，即可拔出卡针。

![NanoKVM Go 系统重置状态](./../../../../assets/NanoKVM/go/reset/nanokvm-go-reset-screen-ready.webp)
