---
title: NanoKVM 静态IP地址修复
---

## 适用情况

1. NanoKVM 被设置为静态 IP 后，无法通过 DHCP 自动获取地址。

## 问题原因

部分批次的 NanoKVM 出厂时被误配置为静态 IP（`192.168.70.70`），因此无法通过 DHCP 获取动态地址。

## 修复步骤

可根据实际情况选择以下任一方法：

### 方法 1：重新烧录固件

重新烧录 NanoKVM 固件，恢复默认网络配置。
具体操作可参考：[烧录系统](https://wiki.sipeed.com/hardware/zh/kvm/NanoKVM/system/flashing.html)。

### 方法 2：可方便拔出 SD 卡

若设备便于取出 SD 卡，可使用读卡器连接电脑，删除 SD 卡第一个分区中的 `eth.nodhcp` 文件。

### 方法 3：不方便拔出 SD 卡（如 Cube 用户）

1. 断电，保持 SD 卡插入。
2. 找到 HID（PC-USB）接口旁边的圆形小孔。**`BOOT` 按键在机壳内部，比小孔更深也更靠下，并不在小孔的正中心**，所以卡针直插到底后往下捅是压不到按键的。
3. 把卡针从小孔插到底，然后**以孔口边缘为支点，把露在机身外的针尾朝机身顶部方向掰**，靠杠杆作用让针尖在机内向下压住 `BOOT` 按键；力度适中，感觉到顶住按键即可。带图解的完整说明见[烧录系统](https://wiki.sipeed.com/hardware/zh/kvm/NanoKVM/system/flashing.html)中的「USB 更新 TF 卡镜像」。
4. **保持向上掰的力度不要松手**，把 USB 线一端插入**小孔旁边那个 USB-C 接口**（HID 接口，位于 HDMI 接口下方），另一端连接到电脑。
5. 等待电脑识别出 U 盘设备；**当 `boot` 盘符出现后**才松开卡针。
6. 删除该分区中的 `eth.nodhcp` 文件。
