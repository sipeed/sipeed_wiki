# 测量精度

## 测试条件

- 镜头：70° FOV，双通滤波片
- 传感器：SC035HGS 黑白全局快门
- 目标：漫反射平面（避免镜面反光）
- 方法：对准已知距离目标，读取中心区域深度均值

## 精度特性

- 两个版本在有效范围内误差均 **≤3%**，典型 **~1%**
- 误差随距离增大略有增长（双目视差精度与距离的平方成反比）
- 长基线版在远距离更稳定（3m 处误差 1.43%），短基线版近距离更精细（0.3m 可测）
- 镜面反光表面会显著降低精度，建议使用漫反射目标测试
- 深度值的 Z 轴噪声（帧间抖动）通常 ≤1%，可通过空间滤波和时间平均进一步降低
